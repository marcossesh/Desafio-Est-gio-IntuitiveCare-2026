# Desafio Técnico - Intuitive Care (2026)

## Visão Geral
Este projeto é a solução para o desafio técnico de admissão de estagiários da Intuitive Care.
O objetivo é realizar a ingestão, limpeza, transformação e análise de dados contábeis de operadoras de saúde (ANS).

## Estrutura do Projeto
- `src/`: Scripts Python para extração e transformação (ETL).
- `sql/`: Scripts SQL para criação de tabelas e cargas.
- `docs/`: Documentação técnica e respostas dissertativas.
